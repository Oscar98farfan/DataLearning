Laboratorio SQL

Una base de datos de práctica para escribir tus propias consultas. Aquí nada se califica: es para experimentar, equivocarte y ver qué pasa.

  1. Mira tus tablas. Abajo están las 4 tablas con sus columnas. Toca Ver datos para ver qué contienen.
  2. Escribe tu consulta en el editor. Borra lo que haya y escribe la tuya. Si tocas el nombre de una columna, se agrega donde tengas el cursor.
  3. Toca Ejecutar y mira el resultado debajo del editor. Si algo sale mal, el error te dice qué revisar.

¿No sabes por dónde empezar? Al final hay ejemplos explicados: cárgalos, ejecútalos y luego cámbialos. Para probar por partes, selecciona unas líneas y toca Ejecutar: corre solo la selección. También puedes comentar líneas con el botón del editor.

Laboratorio de Python

Python y pandas de verdad, dentro de tu navegador. Trabajas con DataFrames de los mismos datos del laboratorio SQL, más una tabla sucia para practicar limpieza.

  1. Inicia Python. La primera vez descarga unos 50 MB (mejor con wifi). Después queda guardado y funciona sin internet.
  2. Mira tus datos. Cada tabla ya es un DataFrame listo para usar: ventas, empleados, clientes_sucios…
  3. Escribe y ejecuta. La última línea se muestra sola (como en Jupyter). Usa print() para ver valores intermedios.

Las variables que creas se conservan entre ejecuciones, como en un notebook. Reiniciar las borra. Para probar por partes, selecciona líneas y toca Ejecutar, o comenta las que no quieras correr.
