Laboratorio de Git

Un repositorio simulado para practicar sin miedo: escribes comandos como en Git Bash y el grafo muestra la historia en vivo. Elige un reto o usa el modo libre.

Historia

Cada punto es un commit; el relleno marca dónde estás (HEAD) y el borde grueso, un commit de fusión. Las etiquetas son las ramas.

Terminal

$

Archivos

Conflicto: deja solo el contenido correcto y borra las líneas <<<<<<<, ======= y >>>>>>>. Luego guarda, haz git add y termina con git commit (o git rebase --continue).

¿Conservar o reescribir la historia?

Regla de oro: en ramas compartidas (main, develop) usa merge o revert. Rebase, reset y squash reescriben: úsalos en tus ramas locales antes de compartirlas.

Laboratorio de IA

Un modelo de lenguaje real no cabe en tu teléfono sin internet, pero sí todo lo que pasa a su alrededor. Aquí ves, paso a paso y en pequeño, cómo funcionan los tokens, la predicción, los embeddings y RAG.

Es una simulación educativa: los números son de juguete, pero la mecánica es la misma que usan Copilot y los demás asistentes.

1. Tokens

El modelo no lee palabras: lee tokens. Escribe y mira cómo se parte el texto.

ids:

Aproximación: cada modelo tiene su propio tokenizador. En español, una palabra suele ocupar entre 1 y 3 tokens.

2. Predecir la siguiente palabra

Un LLM calcula qué tan probable es cada posible siguiente token. Toca una opción para agregarla o genera varias seguidas.

Baja = elige casi siempre la más probable (predecible). Alta = reparte la probabilidad (más creativa y más riesgo de incoherencias).

3. Embeddings: parecido por significado

Compara dos frases. La búsqueda léxica cuenta palabras iguales; la semántica compara significados. Por eso "días libres" encuentra "vacaciones".

4. RAG paso a paso

Pregunta algo sobre las políticas de una empresa ficticia y mira cada paso: fragmentos, recuperación, permisos, prompt enriquecido y respuesta.

Prueba: pregunta "¿Cuándo pagan la quincena?" como Empleado y luego como RR. HH.; o baja la ventana a 120 tokens.
